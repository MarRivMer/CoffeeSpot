# Coffee Spot
---

Coffee Spot is a web application that allows user to search a specific location and purpose for search and the app will use AI/Machine learning to provide the best coffee shops nearby according to your purpose!
* User friendly
* Dependable
* Simple

The app compares and contrasts coffee spots for you, just search and choose. No need to waste time in comparing different places for your needs.
